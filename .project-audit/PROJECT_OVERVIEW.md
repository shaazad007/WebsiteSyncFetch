# Project Overview - Website Sync Fetch

## Overview
**Website Sync Fetch** is a Flutter Android application designed to inspect webpage SEO metrics on demand. The app accepts a target URL, executes an HTTP request, parses the returning HTML document for standard SEO metadata tags, and accumulates the results into a scrollable data table.

## Key Goals
1. Provide a lightweight, mobile-friendly interface for quick SEO checks.
2. Maintain an in-memory session history of fetched pages.
3. Handle network failures and missing metadata gracefully without crashing.
4. Establish an AI audit system for tracking application state across development sessions.
